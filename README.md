# Sorelly — Cardápio Digital

Cardápio digital da Sorelly, crepe francês em Sorocaba.

Site estático em um único arquivo (`index.html`), pronto para o GitHub Pages.

## Publicar no GitHub Pages

1. Crie um repositório no GitHub e envie estes arquivos para a raiz dele.
2. No repositório, abra **Settings → Pages**.
3. Em **Source**, escolha **Deploy from a branch**, selecione a branch `main` e a pasta `/ (root)`, e salve.
4. Em alguns minutos o cardápio fica disponível em `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Editar o cardápio

Os sabores ficam em listas `<li>` dentro de cada categoria do `index.html`.
Ao adicionar ou remover sabores, atualize também os números da capa (`data-count`).
